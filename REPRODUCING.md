# Reproduce the preliminary descriptive findings

Requires Python 3.10 or newer. No third-party packages or API credentials are needed. Clone this repository and run:

```bash
python3 scripts/verify_release.py
```

The command verifies the release's SHA-256 manifest, checks all 304 video rows against transcript counts and all 5,967 reduced interaction codes, regenerates both findings files, and compares every released numeric field against the frozen references. It fails with an exception/nonzero exit on a mismatch. The message PASS concerns aggregation and release integrity only.

To regenerate without the release verification wrapper:

```bash
python3 scripts/build_manuscript_findings.py
python3 scripts/build_manuscript_detail.py
```

Outputs are in `results/`. The second command depends on the ecosystem mapping generated by the first. The supplied references freeze the local manuscript analysis of 6 October 2026. Input hashes change because public records have been minimized; substantive output values are compared in full, excluding source-file/hash metadata and the explicitly omitted illustrative cases.

## Data dictionary

- `data/video-level.csv`: 304 video-level aggregates; includes 278 core E1-E3 and 26 exploratory E4 records. Raw counts, proportions and modality-specific denominators remain separate.
- `data/transcript-codes.jsonl`: 304 numeric/categorical transcript coding summaries, window count, risk/benefit segment totals, evaluation votes, and retained recommendation alternatives. No source quotations or rationales.
- `data/interaction-codes.jsonl`: 5,967 reduced interaction coding records (4,649 comments and 1,318 danmaku). Original unit IDs are replaced with opaque hashes; public video IDs preserve video linkage. No commenter identity, source text, likes, quotation, or session/account metadata is released. This minimization is not a claim of guaranteed anonymization.
- `data/event-metadata.csv`: 4,893 event-pool rows, limited to event, content-cell label and public video link. E4 rows are preserved for mapping but excluded from core supply findings.
- `reference/`: frozen numeric output objects for full comparisons.

## Measures and aggregation

Risk-benefit score = (benefit-segment count - risk-segment count) / (benefit-segment count + risk-segment count), rounded to two decimals; no-signal denominator gives zero. Benefit is not response efficacy. A coded recommendation means an institutional suggestion appears somewhere in the transcript, not a demonstrated effective response.

Frame names in the source table are deterministic count categories, not fitted published-framework clusters. `high-threat` is therefore described in prose as risk-more, not an EPPM high-threat/low-efficacy diagnosis. Recommendation receiver/type counts use the union of retained window alternatives, counting each video once per category; categories overlap.

Comments and danmaku are aggregated separately. Unit-weighted and video-equal-weighted percentages are both reported. Correlations use average tied ranks (Spearman) across videos with comments and are unadjusted descriptive associations. Ecological labels are source classifications, not verified audience residence.

## What this does not reproduce

Collection, transcription, sentence/window segmentation, model judgments from raw text, quote validation, independent semantic review, or coding reliability. The original unredacted local records are separate from this minimized release. No p values, confidence intervals, adjusted causal models or mediation result are supplied. 41 long windows contain only one punctuation-based segment; off-topic discussion and cross-language segmentation need sensitivity checks.
